# Vietnamese pairs whose second syllable a reader would bet on.
#
# Built by hand for Funput, from no external word list or corpus — which is why it
# carries the project's own licence and can be shipped (see NOTICE.md). Predict
# reads it when the user's own pairs have nothing to say yet: after the first
# syllable of a pair and a space, the bar offers the second.
#
# Layout: one pair per line, the two syllables separated by one space, lowercase
# NFC, tone marks placed the modern way (`khoẻ`, not `khỏe`; the engine respells
# for the traditional style). Any `#` line is a comment.
#
# What belongs here: a first syllable that, in everyday chat, is followed by this
# second syllable most of the time. Predict only ever offers one word, so a first
# syllable with two strong continuations (`xin` → `chào` / `lỗi` / `phép`) does
# not belong, and neither do the syllables anything can follow (`của`, `và`, `là`).
# Offering a wrong word is worse than offering none. No proper nouns: Predict
# cannot capitalise `nội` after `Hà`.
#
# Every line is checked by `funput-lexicon-tool/tests/vi_pairs.rs`. That check
# cannot tell whether a pair is sharp enough, so additions want a second pair of
# eyes.
