# Common Vietnamese syllables, most common first.
#
# Built by hand for Funput, from no external word list — which is why it carries
# the project's own licence and can be shipped. It is deliberately short: typo
# correction uses it to answer "is this a syllable anyone actually writes", and a
# missing entry only costs a repair, while a wrong entry could let a real word be
# rewritten. Starting narrow and growing is the safe direction.
#
# Every line is checked against `funput_core::is_complete_syllable` by
# `tests/syllables.rs`, so a malformed spelling cannot reach a device. That check
# cannot tell a real word from a structurally valid non-word, so additions want a
# second pair of eyes.
#
# Order is rough frequency, and only rough: it is read as a ranking, never as a count.
