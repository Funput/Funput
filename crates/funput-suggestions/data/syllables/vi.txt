# Common Vietnamese syllables, ranked in four bands.
#
# Built by hand for Funput, from no external word list — which is why it carries
# the project's own licence and can be shipped (see NOTICE.md). Typo correction
# reads it as a *prior*: a candidate on the list is more likely to be what the
# user meant, and the band it sits in says by how much. It is a ranking, never a
# count: no entry carries a number, and nothing here was measured over a corpus.
#
# Layout: `## tier N` opens a band (1 = the words that hold a sentence together,
# 4 = rare but real), one syllable per line, lowercase NFC, no entry in two bands.
# Within a band the order is rough frequency, most common first, and only rough.
# A syllable whose tone can sit on either vowel of `oa`, `oe`, `uy` is listed in
# both spellings (`hoà` and `hòa`), because the engine writes whichever style the
# user chose and the lookup compares bytes.
# Any other `#` line is a comment, so readers that predate the bands still see a
# flat list.
#
# Every line is checked against `funput_core::is_complete_syllable` by
# `funput-lexicon-tool/tests/vi_syllables.rs`, so a malformed spelling cannot
# reach a device. That check cannot tell a real word from a structurally valid
# non-word, so additions want a second pair of eyes.
