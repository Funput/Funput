<summary><strong>Cam kết quyền riêng tư</strong></summary>
<br>

Bộ gõ nhìn thấy mọi thứ bạn gõ, nên Funput giữ những cam kết sau và bạn có thể tự kiểm chứng trong mã nguồn:

- **Không thu thập dữ liệu.** Không có SDK thống kê, quảng cáo hay báo lỗi tự động. Không cần tài khoản.
- **Chữ bạn gõ ở lại trên máy.** Gợi ý từ, từ điển cá nhân và những gì bàn phím học được đều lưu cục bộ.
- **Bàn phím Android không có quyền truy cập mạng.** Quyền Internet bị gỡ khỏi tiến trình bàn phím ngay lúc build. Chỉ app cài đặt dùng mạng để tải tin tức.
- **Không tự đọc clipboard.** Trên iOS, bàn phím chỉ dán khi bạn bấm nút Dán của hệ thống.

</details>

## Dành cho nhà phát triển

Năm nền tảng dùng chung một lõi Rust. iOS, macOS và Linux gọi qua [`funput-ffi`](crates/funput-ffi) (C ABI), Android qua [`funput-jni`](crates/funput-jni), còn Windows link thẳng [`funput-engine`](crates/funput-engine).

<details>
<summary><strong>Xem sơ đồ kiến trúc</strong></summary>
<br>
<p align="center">
  <a href="assets/design/architecture.png">
    <img src="assets/design/architecture.png" width="900" alt="Kiến trúc Funput: iOS, macOS, Linux qua funput-ffi; Android qua funput-jni; Windows link trực tiếp; tất cả hội về funput-engine và funput-core">
  </a>
</p>
</details>

Chạy test cho phần lõi:

```bash
cargo test --workspace
```

Hướng dẫn build cho từng nền tảng nằm trong README riêng:
[iOS](platforms/ios/README.md), [Android](platforms/android/README.md), [macOS](platforms/macos/README.md), [Windows](platforms/windows/README.md), [Linux](platforms/linux/README.md).
Thiết kế của từng tính năng được ghi ở [`docs/features`](docs/features).

Funput đang được phát triển tích cực và có bản mới thường xuyên. Mọi báo lỗi, thảo luận và pull request đều được chào đón.
