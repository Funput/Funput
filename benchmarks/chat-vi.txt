# Chat-style Vietnamese for `funput dev suggest`. Written for Funput, MIT (same as the repo).
# Everyday messages, one per line. Not drawn from any corpus and deliberately not built from
# crates/funput-suggestions/data/pairs/vi.txt, so the shipped pairs are not graded on their own
# list. It is small on purpose: it keeps the tests honest and fast. Real measurements should run
# on a larger text of your own in benchmarks/.corpus/ (gitignored).
